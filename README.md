# 🎮 Tic Tac Toe Game

A responsive Tic Tac Toe game built using HTML, CSS, and JavaScript.


## ✨ Features

- Two-player gameplay (X and O)
- Winner detection
- Reset Game button
- New Game button
- Responsive design
- Draw Detection

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🚀 How to Run

Open `index.html` in your browser and start playing.

## 📚 Concepts Used

- DOM Manipulation
- Event Listeners
- Arrays
- Loops
- Functions
- CSS Flexbox
