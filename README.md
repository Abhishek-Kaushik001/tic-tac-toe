# Tic Tac Toe Game

A simple Tic Tac Toe game built using HTML, CSS, and JavaScript.

## Features

- Two-player game (X and O)
- Winner detection
- Reset Game button
- New Game button

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Open index.html in your browser.
2. Start playing the game.
